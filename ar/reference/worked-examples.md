# أمثلة محلولة

عشر صفقات وسيناريوهات كاملة، من البداية إلى النهاية، بكل رقم معروضًا. احسب كلًّا منها بنفسك
قبل قراءة الحلّ.

كل الأرقام توضيحية. ويُفترَض حساب بالدولار الأمريكي في كل المواضع. والتكاليف تستخدم عمولة
3.50 دولارات لكل لوت في كل اتجاه في العملات ما لم يُذكر غير ذلك.

---

## 1. صفقة رابحة نموذجية

**الإعداد.** حساب 5,000 دولار، ومخاطرة 0.5%. EUR/USD في اتجاه صاعد على H4، مرتدًّا إلى مستوى
مقاومة سابق يعمل الآن دعمًا.

**تحديد الحجم**

| | |
|---|---|
| ميزانية المخاطرة | 5,000 × 0.5% = **25.00 دولارًا** |
| الدخول (سعر الطلب) | 1.0855 |
| الوقف (تحت القاع السابق عند 1.0828) | 1.0820 |
| مسافة الوقف | 35 نقطة |
| الوحدات | 25 ÷ (35 × 0.0001) = 7,142 ← **0.07 لوت** |
| قيمة النقطة | 0.70 دولار |
| **المخاطرة الفعلية** | 35 × 0.70 = **24.50 دولارًا (0.49%)** |
| الهدف (القمّة السابقة) | 1.0940 |
| العائد | 85 نقطة |
| **العائد إلى المخاطرة** | **2.43 : 1** |
| القيمة الاسمية | 7,000 × 1.0855 = 7,598 دولارًا |
| الهامش عند 30:1 | 253 دولارًا |
| **الرافعة الفعلية** | **1.5 : 1** |

**التكاليف**

| | |
|---|---|
| العمولة (0.07 × 3.50 × 2) | −0.49 دولار |
| التمويل، 3 ليالٍ (0.07 × 7.85) | −1.65 دولار |
| **الإجمالي** | **−2.14 دولار** |
| نسبة التكلفة | 2.14 ÷ 24.50 = **8.7%** — مستدامة |

**النتيجة.** بلوغ الهدف في اليوم الثالث.

| | |
|---|---|
| الإجمالي | 85 × 0.70 = +59.50 دولارًا |
| التكاليف | −2.14 دولار |
| **الصافي** | **+57.36 دولارًا** |
| **مضاعف R** | **+2.34R** |

**ملاحظة.** مضاعف R هو 2.34 لا 2.43 المخطَّط، لأن التكاليف تُدفَع على المخاطرة والعائد معًا.
دوّن دائمًا R المتحقّق لا المخطَّط.

## 2. صفقة خاسرة نموذجية

الصفقة الأهمّ، لأن معظم الصفقات تخسر.

**الإعداد.** الحساب نفسه 5,000 دولار، ومخاطرة 0.5%. GBP/USD، بيع من مقاومة نطاق.

| | |
|---|---|
| ميزانية المخاطرة | 25.00 دولارًا |
| الدخول (سعر العرض) | 1.2680 |
| الوقف (فوق قمّة النطاق) | 1.2722 |
| مسافة الوقف | 42 نقطة |
| الوحدات | 25 ÷ (42 × 0.0001) = 5,952 ← **0.05 لوت** |
| قيمة النقطة | 0.50 دولار |
| المخاطرة المخطَّطة | 42 × 0.50 = **21.00 دولارًا** |

**النتيجة.** الخروج بالوقف في اليوم الثاني، بانزلاق قدره نقطة واحدة.

| | |
|---|---|
| الخروج الفعلي (سعر الطلب) | 1.2723 |
| المسافة الفعلية | 43 نقطة |
| الإجمالي | −21.50 دولارًا |
| العمولة | −0.35 دولار |
| التمويل، ليلتان (سواب موجب على هذا البيع) | +0.02 دولار |
| **الصافي** | **−21.83 دولارًا** |
| **مضاعف R** | **−1.04R** |

**ملاحظة.** صفقة «−1R» هي في الحقيقة −1.04R متى أُدخل الانزلاق والعمولة. وعلى مدى مئة صفقة
يبلغ ذلك الفرق نحو 4R، وهو في استراتيجية هامشية الأفضليةُ كلّها. ولهذا ينبغي فحص متوسط
الخسارة في سجلّك في مواجهة −1.0R.

## 3. التمويل على مدى أسبوع

**الإعداد.** حساب 10,000 دولار، ومخاطرة 1%. شراء عقد فروقات على مؤشّر US 500، والاحتفاظ عبر
نهاية الأسبوع.

| | |
|---|---|
| ميزانية المخاطرة | 100.00 دولار |
| الدخول | 5,150 |
| الوقف | 5,105 (45 نقطة) |
| قيمة النقطة | دولار واحد لكل عقد |
| الحجم | 100 ÷ 45 = 2.22 ← **عقدان** |
| المخاطرة الفعلية | 45 × 2 = **90.00 دولارًا** |
| القيمة الاسمية | 2 × 5,150 = 10,300 دولار |
| الهامش عند 5% | 515 دولارًا |
| الرافعة الفعلية | 1.03 : 1 |
| الهدف | 5,240 (90 نقطة) |

**التمويل.** سعر المرجع 5.0% + هامش الوسيط 2.5% = 7.5%، وعدد أيام السنة 365.

```
لكل ليلة = 10,300 × 0.075 ÷ 365 = 2.12 دولار
الاحتفاظ من الاثنين إلى الاثنين التالي = 7 أيام مفروضة
الإجمالي = 14.81 دولارًا
```

**النتيجة.** بلوغ الهدف.

| | |
|---|---|
| الإجمالي | 90 × 2 = +180.00 دولارًا |
| التمويل | −14.81 دولارًا |
| **الصافي** | **+165.19 دولارًا** |
| **مضاعف R** | **+1.84R** |

**ملاحظة.** استهلك التمويل **8% من الربح الإجمالي في أسبوع واحد**. وعلى مدى فصل كان
ليستهلك معظمه. وهذا هو السبب البنيوي في كون عقود الفروقات أداة قصيرة الأفق.

## 4. فجوة أرباح

السيناريو الذي يجب على كل متداول عقود فروقات على الأسهم فهمه قبل الاحتفاظ بواحد ليلًا.

**الإعداد.** حساب 20,000 دولار، ومخاطرة 1%. شراء سهم عند 62.00 دولارًا، ووقف 59.00. وتُعلَن
الأرباح بعد الإغلاق في اليوم الثالث.

| | |
|---|---|
| ميزانية المخاطرة | 200.00 دولار |
| مسافة الوقف | 3.00 دولارات |
| الحجم | 200 ÷ 3.00 = 66.7 ← **66 عقدًا** |
| المخاطرة المخطَّطة | **198.00 دولارًا** |
| القيمة الاسمية | 66 × 62 = 4,092 دولارًا |
| الهامش عند 20% | 818 دولارًا |

**النتيجة.** نتائج مخيّبة. ويفتح السهم عند **48.50 دولارًا**، أدنى بكثير من الوقف.

| | |
|---|---|
| سعر التنفيذ | 48.50 دولارًا |
| الإجمالي | (62.00 − 48.50) × 66 = **−891.00 دولار** |
| العمولة (0.1% في كل اتجاه، بحدّ أدنى 10 دولارات، في الاتجاهين) | −20.00 دولارًا |
| التمويل، 3 ليالٍ | −2.52 دولار |
| **الصافي** | **−913.52 دولارًا** |
| **مضاعف R** | **−4.61R** |
| كنسبة من الحساب | **−4.6%** |

**ملاحظة.** مركزٌ حُدِّد حجمه للمخاطرة بـ 1% خسر 4.6%. ولم يفشل الوقف، بل لم يكن قابلًا
للبلوغ أصلًا. ومواعيد الأرباح تُنشَر مسبقًا، وهو ما يجعل هذه مخاطرة **متوقَّعة وقابلة
للتجنّب**. والاستجابات المتاحة كانت: الإغلاق قبل الإعلان، أو تقليل الحجم، أو دفع ثمن وقف
مضمون.

## 5. تحديد الحجم بالتقلّب، ومشكلة الحدّ الأدنى

**الإعداد.** الذهب، وATR(14) على D1 = 24.00 دولارًا. والوقف عند 2 ATR. وحجم العقد 100 أونصة
للوت، والحدّ الأدنى 0.01 لوت.

**الحالة أ — حساب 10,000 دولار، ومخاطرة 0.5%**

| | |
|---|---|
| ميزانية المخاطرة | 50.00 دولارًا |
| الدخول | 2,395 دولارًا |
| الوقف (2 ATR) | 2,347 — **على بعد 48.00 دولارًا** |
| الأونصات | 50 ÷ 48 = 1.04 أونصة |
| أدنى حجم قابل للتداول | 0.01 لوت = أونصة واحدة |
| الحجم | **0.01 لوت** |
| المخاطرة الفعلية | 48 × 1 = **48.00 دولارًا (0.48%)** |

يناسب، بالكاد.

**الحالة ب — حساب 8,000 دولار، ومخاطرة 0.5%**

| | |
|---|---|
| ميزانية المخاطرة | 40.00 دولارًا |
| أدنى مخاطرة للمركز | 48.00 دولارًا |
| المخاطرة كنسبة من الحساب | **0.60%** |

**فالحدّ الأدنى لحجم الصفقة يجعل التحديد الصحيح مستحيلًا.** فرقم الـ 0.6% يتجاوز الميزانية
بنسبة 20%.

والاستجابات الصحيحة: تداول أداة أخرى، أو استخدام إطار زمني أطول حيث يعني الوقف الأوسع أن
المخاطرة نفسها تشتري مركزًا أصغر، أو عدم دخول الصفقة. **والاستجابة غير الصحيحة أبدًا هي رفع
نسبة المخاطرة لتلائم**، لأن ذلك يحوّل قيدًا إلى قاعدة مهجورة.

## 6. حين تكون العملة الأساس هي عملة حسابك

**الإعداد.** حساب 6,000 دولار، ومخاطرة 1%. شراء USD/JPY عند 149.80.

وقيمة النقطة هنا **ليست** 10 دولارات لكل لوت وهي **تنزاح مع حركة السعر**.

| | |
|---|---|
| ميزانية المخاطرة | 60.00 دولارًا |
| الدخول | 149.80 |
| الوقف | 149.35 (45 نقطة) |
| قيمة النقطة لكل وحدة | 0.01 ÷ 149.80 = 0.00006676 دولار |
| الوحدات | 60 ÷ (45 × 0.00006676) = 19,973 ← **0.19 لوت** |
| قيمة النقطة عند 0.19 لوت | (0.01 × 19,000) ÷ 149.80 = **1.268 دولار** |
| المخاطرة الفعلية | 45 × 1.268 = **57.07 دولارًا (0.95%)** |
| الهدف | 150.70 (+90 نقطة) |

**النتيجة.** بلوغ الهدف في اليوم الثالث.

| | |
|---|---|
| الإجمالي، بالين | 0.90 × 19,000 = 17,100 ين |
| محوَّلًا بسعر الإغلاق 150.70 | **+113.47 دولارًا** |
| العمولة (0.19 × 3.50 × 2) | −1.33 دولار |
| التمويل، 3 ليالٍ (سواب موجب، شراء USD/JPY) | +1.82 دولار |
| **الصافي** | **+113.96 دولارًا** |
| **مضاعف R** | **+2.00R** |

**لاحظ أمرين.** أن الربح بالين يُحوَّل بسعر **الإغلاق** لا بسعر الدخول. وأن قيمة النقطة
ارتفعت من 1.268 إلى 1.272 دولار مع ارتفاع السعر، فانزاحت مخاطرتك لكل نقطة انزياحًا طفيفًا
والمركز مفتوح. وكلاهما خاصّ بالأزواج التي تكون فيها عملة حسابك هي العملة الأساس.

## 7. استراتيجية مضاربة سريعة تدمّرها التكاليف

**الإعداد.** حساب 2,000 دولار، ومخاطرة 1%. EUR/USD، بوقف 8 نقاط وهدف 12 نقطة، و30 صفقة
شهريًّا.

| | |
|---|---|
| ميزانية المخاطرة | 20.00 دولارًا |
| الوحدات | 20 ÷ (8 × 0.0001) = 25,000 ← **0.25 لوت** |
| قيمة النقطة | 2.50 دولارات |
| المخاطرة المخطَّطة | **20.00 دولارًا** |
| العائد إلى المخاطرة | 1.5 : 1 |

**التكاليف للصفقة الكاملة**

| | |
|---|---|
| الفارق السعري، نقطة واحدة | 25,000 × 0.0001 = 2.50 دولارات |
| العمولة (0.25 × 3.50 × 2) | 1.75 دولار |
| **الإجمالي** | **4.25 دولارات** |
| **نسبة التكلفة** | 4.25 ÷ 20 = **21%** |

**الأثر في النتائج**

| | إجماليًّا | صافيًا |
|---|---|---|
| صفقة رابحة | +30.00 دولارًا (+1.50R) | +25.75 دولارًا (**+1.29R**) |
| صفقة خاسرة | −20.00 دولارًا (−1.00R) | −24.25 دولارًا (**−1.21R**) |

**نسبة الربح عند التعادل**

```
إجماليًّا: 1 ÷ (1 + 1.5)                        = 40.0%
صافيًا:   25.75 ن = 24.25(1 − ن)  ←  ن = 24.25÷50 = 48.5%
```

**فالتكاليف ترفع نسبة الربح المطلوبة من 40% إلى 48.5%**، وهو فرق هائل في مقدار ما يجب أن
تكون عليه الاستراتيجية من جودة.

**التكلفة السنوية**

```
30 صفقة × 4.25 = 127.50 دولارًا شهريًّا
                = 1,530 دولارًا سنويًّا
                = 76.5% من الحساب البالغ 2,000 دولار، سنويًّا، تكاليفَ فقط
```

**ملاحظة.** الاستراتيجية ليست سيئة بالضرورة. بل إن الجمع بين حساب صغير ووقف ضيّق وتواتر
تداول مرتفع هو ما يجعلها غير صالحة. والقواعد نفسها على إطار يومي، بوقف 100 نقطة وأربع صفقات
شهريًّا، ستكون نسبة تكلفتها دون 3%.

## 8. محفظة مترابطة في يوم سيئ

**الإعداد.** حساب 10,000 دولار. ثلاثة مراكز، كلٌّ منها يبدو معقولًا بمفرده.

| المركز | القيمة الاسمية | الهامش |
|---|---|---|

| شراء 8 عقود US 500 عند 5,150 | 41,200 دولارًا | 2,060 دولارًا |
| **الإجمالي** | **157,400 دولارًا** | **5,933 دولارًا** |

| | |
|---|---|
| مستوى الهامش | 10,000 ÷ 5,933 = **169%** |
| **الرافعة الفعلية** | **15.7 : 1** |
| عامل المخاطرة | الثلاثة كلها بيعٌ للدولار و/أو شراءٌ للمخاطرة |

**اليوم الأول.** دولار قوي، ونفور من المخاطرة.

| المركز | الحركة | الربح/الخسارة |
|---|---|---|
| EUR/USD | −120 نقطة بـ 6.00 دولارات للنقطة | −720 دولارًا |
| GBP/USD | −150 نقطة بـ 4.00 دولارات للنقطة | −600 دولار |
| US 500 | −90 نقطة بـ 8.00 دولارات للنقطة | −720 دولارًا |
| **الإجمالي** | | **−2,040 دولارًا** |

| | |
|---|---|
| حقوق الملكية | 7,960 دولارًا |
| الهامش المستخدَم (مُعاد حسابه) | نحو 5,884 دولارًا |

**اليوم الثاني.** تستمرّ الحركة بمقدار مشابه: −2,000 دولار أخرى.

| | |
|---|---|
| حقوق الملكية | 5,960 دولارًا |

المخاطرة، معبَّرًا عنه بثلاث صيغ، برافعة فعلية 15.7:1. **وحركة معاكسة قدرها 2.6% عبر
المحفظة أنتجت خسارة 20% من الحساب في يومين**، ولم يكن أيٌّ من المراكز المفردة غير معتاد.

## 9. شهر من النتائج

**الإعداد.** حساب 5,000 دولار، ومخاطرة 0.5%. فتكون 1R = 25 دولارًا. وعشرون صفقة.

**الرابحة (8):** +2.4R، +1.8R، +3.1R، +2.0R، +1.2R، +2.6R، +0.8R، +2.2R = **+16.1R**

**الخاسرة (12):** −1.0R × 9، و−1.05R، و−1.10R، و−0.60R (خروج مبكر عند بطلان الفرضية) =
**−11.75R**

| المقياس | القيمة |
|---|---|
| الصفقات | 20 |
| نسبة الربح | 40% |
| متوسط الربح | 16.1 ÷ 8 = **+2.01R** |
| متوسط الخسارة | 11.75 ÷ 12 = **−0.98R** |
| **التوقّع** | (0.40 × 2.01) − (0.60 × 0.98) = **+0.22R** |
| **عامل الربح** | 16.1 ÷ 11.75 = **1.37** |
| الإجمالي | **+4.35R = 108.75 دولارًا** |
| العائد | **+2.2%** |

**قراءتها.**

تخسر الاستراتيجية في 60% من الصفقات وتربح المال، وهو بالضبط ما يتنبّأ به جدول التعادل عند
متوسط ربح 2R.

ومتوسط الخسارة −0.98R لا −1.00R، وهو أمر صحّي — فالخروج المبكر عند بطلان الفرضية بـ −0.60R
سحبه دون الواحد، ولا توجد خسائر تتجاوز −1.1R، فالوقوف تُحترَم.

**وحجم العيّنة: عشرون صفقة لا تدعم أي استنتاج إطلاقًا.** فالتوقّع الحقيقي قد يكون معقولًا في
أي مكان من سالب قليلًا إلى +0.6R. واصل، ولا تكبّر الحجم، ولا تغيّر شيئًا.

## 10. مقارنة نوعَي حساب على مدى سنة

**الإعداد.** متوسط الحجم 0.4 لوت، و20 صفقة كاملة شهريًّا.

**الحساب أ — قياسي، بفارق 1.3 نقطة، بلا عمولة**

```
الفارق للصفقة الكاملة = 40,000 × 0.00013 = 5.20 دولارات
شهريًّا = 20 × 5.20                        = 104.00 دولارًا
سنويًّا                                     = 1,248 دولارًا
```

**الحساب ب — خام، بفارق 0.3 نقطة، مع 3.50 دولارات لكل لوت في كل اتجاه**

```
الفارق     = 40,000 × 0.00003         = 1.20 دولار
العمولة    = 0.4 × 3.50 × 2            = 2.80 دولارات
للصفقة الكاملة                          = 4.00 دولارات
شهريًّا = 20 × 4.00                      = 80.00 دولارًا
سنويًّا                                   = 960 دولارًا
```

**الفرق: 288 دولارًا سنويًّا.** وعلى حساب قيمته 5,000 دولار فذلك **5.8% من الحساب سنويًّا**،
وهو أكبر من أفضلية استراتيجيات كثيرة بأكملها.

**ملاحظة.** الجواب يتوقّف على حجمك. فعند 0.1 لوت تكون العمولة 0.70 دولار والوفر في الفارق
