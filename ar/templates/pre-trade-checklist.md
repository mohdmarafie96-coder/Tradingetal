# قائمة ما قبل الصفقة

أكملها **كاملةً** قبل كل صفقة. مادّيًّا. في تسعين ثانية.

وإن تعذّر وضع علامة في أي مربّع، **فلا تُؤخَذ الصفقة.**

---

**التاريخ / الوقت:** ___________  **الأداة:** ___________  **الاتجاه:** ___________

## الإعداد

- [ ] يوجد إعداد محدَّد من خطّتي — أيّها؟ ___________
- [ ] كل شرط من شروط ذلك الإعداد مستوفى
- [ ] لا يوجد شرط مُبطِل
- [ ] اتجاه الإطار الزمني الأعلى موافق
- [ ] أستطيع ذكر فرضيتي في جملة واحدة: ______________________________________

## المستويات

- [ ] سعر الدخول / المحفّز: ___________
- [ ] سعر الوقف: ___________ — مبرَّر بـ: ___________
- [ ] مسافة الوقف: ______ نقطة
- [ ] الوقف يبعد عن الدخول ______ على الأقل (حدّي الأدنى، مثلًا 1.5 ATR)
- [ ] سعر الهدف: ___________ — مبرَّر بـ: ___________
- [ ] العائد إلى المخاطرة: ______ : 1 — يستوفي حدّي الأدنى البالغ ______

## تحديد الحجم

- [ ] حقوق ملكية الحساب: ___________
- [ ] ميزانية المخاطرة (___% ): ___________
- [ ] حجم المركز المحسوب: ___________ (**مقرَّبًا إلى الأسفل**)
- [ ] المخاطرة الفعلية بالعملة: ___________
- [ ] المخاطرة الفعلية كنسبة من حقوق الملكية: ______%
- [ ] الحجم عند الحدّ الأدنى للمنصّة أو فوقه

## حالة الحساب

- [ ] القيمة الاسمية: ___________
- [ ] الرافعة الفعلية بعد هذه الصفقة: ______ : 1 — ضمن حدّي
- [ ] إجمالي المخاطرة المفتوحة شاملةً هذه الصفقة: ______% — ضمن حدّي
- [ ] انكشاف مجموعة الترابط: ______% — ضمن حدّي
- [ ] عدد المراكز المفتوحة بعد هذه: ______ — ضمن حدّي
- [ ] مستوى الهامش بعد هذه الصفقة: ______%

## التكاليف

- [ ] التكلفة الكاملة المقدَّرة للصفقة: ___________
- [ ] نسبة التكلفة (التكلفة ÷ المخاطرة): ______% — دون 25%
- [ ] الليالي المتوقَّعة للاحتفاظ: ______؛ وتكلفة التمويل: ___________

## الأحداث

- [ ] رُوجعت الرزنامة الاقتصادية
- [ ] لا إصدار عالي الأثر ضمن نافذتي المعلَنة
- [ ] لا إعلان أرباح قبل خروجي المتوقَّع (للأسهم)
- [ ] رُوعي انكشاف نهاية الأسبوع
- [ ] رُوعي التدوير / التبييت الثلاثي

## الحدود

- [ ] لم أبلغ حدّ خسارتي اليومي
- [ ] لم أبلغ حدّ خسارتي الأسبوعي
- [ ] لا تظهر عليّ حاليًّا أي علامة إنذار انفلات من قائمتي
- [ ] لا آخذ هذه الصفقة لاسترداد خسارة سابقة

## التنفيذ

- [ ] سيوضَع الأمر أمرًا مركّبًا، بوقف وهدف ملحَقَين
- [ ] ستُكتَب مذكّرة السجلّ فورًا، قبل معرفة النتيجة

---

**هل وُضِعت كل العلامات؟** إن لم يكن، **فلا تتداول.**
