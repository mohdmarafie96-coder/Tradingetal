# 10.1 — اختيار وسيط

## ترتيب الأولويات

ترتّب معظم مواقع المقارنة الوسطاء بالفارق السعري. وذلك هو الاعتبار الرابع تقريبًا في
الأهمية.

والترتيب الصحيح:

1. **التنظيم وسلامة الأموال** — هل تستطيع استرداد مالك؟
2. **التكلفة الإجمالية** — الفارق السعري زائد العمولة زائد التمويل زائد التحويل
3. **جودة التنفيذ** — هل تحصل على السعر الذي تراه؟
4. **نطاق الأدوات وأحجام العقود** — هل تستطيع تحديد حجمك تحديدًا صحيحًا؟
5. **المنصّة والأدوات**
6. **الدعم وعملية السحب**

فالوسيط ذو أضيق الفوارق وبلا تنظيم ذي معنى ليس رخيصًا. بل هو مخاطرة خسارة كاملة مع خصم
صغير مرفق.

## 1. التنظيم

**تحقّق من الكيان القانوني المحدّد في اتفاقية حسابك**، في السجلّ العام للجهة التنظيمية نفسها.
لا العلامة التجارية. ولا شارة على الموقع.

| الجهة التنظيمية | الولاية القضائية | السجلّ |
|---|---|---|
| FCA | المملكة المتحدة | https://register.fca.org.uk |
| BaFin | ألمانيا | https://www.bafin.de |
| CySEC | قبرص | https://www.cysec.gov.cy |
| AMF | فرنسا | https://www.amf-france.org |
| ASIC | أستراليا | https://asic.gov.au |
| MAS | سنغافورة | https://eservices.mas.gov.sg/fid |
| FSCA | جنوب أفريقيا | https://www.fsca.co.za |
| FINMA | سويسرا | https://www.finma.ch |

**وتحقّق من تبديل الكيانات.** فبنية شائعة جدًّا: علامة تجارية تشغّل «Broker Ltd» منظَّمة من
FCA و«Broker International Ltd» مسجَّلة في سانت فنسنت وجزر غرينادين. ويُضَمّ عملاء بعض الدول
إلى الكيان الخارجي. والموقع والمنصّة وموظّفو الدعم متطابقون. والحمايات ليست كذلك.

واسم الكيان في اتفاقية العميل. اقرأها قبل الإيداع.

**ما يمنحك إيّاه التنظيم الجيد:**

- سقوف رافعة ملائمة للأداة
- حماية إلزامية من الرصيد السالب
- فصل أموال العملاء
- عضوية في نظام تعويض
- أمينُ مظالم أو مسار شكاوى مكافئ
- إفصاحات مخاطر إلزامية تشمل إحصاءات خسائر الشركة نفسها

**قائمة التحقّق:**

- [ ] اسم الكيان من اتفاقية العميل موجودٌ في سجلّ الجهة التنظيمية
- [ ] الترخيص ساري المفعول، وأذوناته تغطّي عقود الفروقات
- [ ] فُحص السجلّ التأديبي
- [ ] فصل أموال العملاء مؤكَّد في الشروط
- [ ] نظام التعويض وحدّه محدَّدان
- [ ] الحماية من الرصيد السالب مؤكَّدة كتابةً
- [ ] النسبة المنشورة لحسابات الأفراد الخاسرة موجودة

## 2. التكلفة الإجمالية

قارن بـ**التكلفة الإجمالية لنمط تداولك الفعلي**، لا بالفارق السعري المعلَن.

ابنِ هذا الجدول لكل مرشَّح، مستخدمًا حجمك المتوقَّع الحقيقي ومدة احتفاظك:

| | الوسيط أ | الوسيط ب |
|---|---|---|
| متوسط الفارق السعري على أداتك | | |
| العمولة لكل لوت في كل اتجاه | | |
| تكلفة الفارق للصفقة الكاملة بحجمك | | |
| العمولة للصفقة الكاملة بحجمك | | |
| التمويل الليلي، شراء، لكل ليلة | | |
| التمويل الليلي، بيع، لكل ليلة | | |
| هامش تحويل العملة | | |
| رسم الخمول وفترة تفعيله | | |
| رسم السحب | | |
| **إجمالي التكلفة للصفقة الكاملة، محتفَظًا بها ن ليلة** | | |
| **التكلفة السنوية المقدَّرة بتواتر تداولك** | | |

**وقِس الفارق السعري بنفسك.** فالأرقام المعلَنة متوسّطات مأخوذة في أكثر الساعات سيولةً، أو
أرقام «ابتداءً من» تقع نادرًا. افتح حسابًا تجريبيًّا وسجّل الفارق في الأوقات التي تتداول فيها
فعلًا، لمدة أسبوع.

## 3. جودة التنفيذ

يصعب تقييمها قبل فتح حساب، وهي مهمّة.

**المؤشّرات التي تبحث عنها:**
- إحصاءات تنفيذ منشورة (بعض الوسطاء المنظَّمين ملزَمون بنشرها)
- هل يُمرَّر الانزلاق الموجب، منصوصًا عليه في سياسة التنفيذ
- المسافات الدنيا للوقف — والأصغر أفضل
- مراجعات مستقلّة تذكر التنفيذ أثناء الأخبار تحديدًا

**وقِسها بعد الفتح**، بطريقة العشرين صفقة من الدرس 05.3.

## 4. الأدوات وأحجام العقود

- هل يقدّم الأدوات التي تريدها؟
- **ما الحدّ الأدنى لحجم الصفقة؟** وهو حاسم على حساب صغير، وفق الدرس 06.1. فالوسيط ذو الحدّ
  الأدنى 0.01 لوت أنفع ماديًّا لحساب قيمته 500 وحدة من الوسيط ذي الحدّ الأدنى 0.1 لوت.
- هل تُنشَر مواصفات العقود بوضوح وكاملةً؟
- ساعات التداول لأدواتك

## 5. المنصّة

ميتاتريدر 4 و5، وcTrader، والتكامل مع TradingView، أو منصّة خاصّة. وكلها كافية. والمنصّة
أقلّ المعايير الستّة أهمية وأكثرها تسويقًا.

وما يهمّ فعلًا: وضع أوامر موثوق، ومواصفات عقود مرئية، وتصدير قابل للاستخدام لسجلّ الأوامر
من أجل سجلّك، والاستقرار في الظروف المتقلّبة.

## 6. الدعم والسحوبات

**السحوبات أفضل اختبار مفرد لوسيط.** فقبل إيداع أي مبلغ معتبر:

1. أودع مبلغًا صغيرًا
2. تداول قليلًا
3. **واسحبه**
4. وسجّل كم استغرق وما الذي طُلب منك

فالوسيط الذي يجعل الإيداع فوريًّا والسحب صعبًا يخبرك بشيء مهمّ، وهو نمط الشكوى الأشيع بشأن
الشركات الإشكالية.

وابحث تحديدًا عن شكاوى السحب بشأن أي وسيط تفكّر فيه. فالنمط مرئي مسبقًا والناس يصفونه
بالتفصيل.

## العلامات الحمراء

- منظَّم خارجيًّا فقط، أو غير منظَّم إطلاقًا
- رافعة تتجاوز السقوف القضائية لعملاء الأفراد
- مكافآت إيداع أو حوافز تداول
- ضغط لإيداع المزيد، أو للترقية إلى صفة محترف
- «مدير حساب» يقترح صفقات أو يعرض التداول نيابةً عنك
- ضمان عوائد أو ادّعاءات ربح من أي نوع
- صعوبات سحب يبلّغ عنها عدّة مستخدمين مستقلّين
- عدم نشر مواصفات العقود
- عدم نشر إحصاءات الخسائر حيث تكون مطلوبة قانونًا
- الاتّصال البارد

وأيٌّ من هذه سبب للبحث في مكان آخر. فالوسطاء المنظَّمون كثيرون، ولا حاجة إلى قبول شركة عليها
علامات تحذير.

## النقاط الأساسية

- التنظيم أولًا، والتكلفة ثانيًا، والتنفيذ ثالثًا، والفارق السعري وحده مقياس مقارنة رديء
- تحقّق من الكيان القانوني في اتفاقية العميل، في سجلّ الجهة التنظيمية نفسها
- تبديل الكيانات بين الذراعين الداخلي والخارجي شائع وذو أثر
- قارن التكلفة الإجمالية بحجمك الحقيقي ومدة احتفاظك
- الحدّ الأدنى لحجم الصفقة يحدّد هل التحديد الصحيح للحجم ممكن
- اختبر السحب مبكرًا بمبلغ صغير
- المكافآت والعوائد المضمونة ومديرو الحسابات الذين يقترحون صفقات كلّها أسباب استبعاد

## تمرين 10.1

**(أ)** خذ وسيطك التجريبي الحالي. وابحث عن الكيان القانوني في اتفاقية العميل، وتحقّق منه في
سجلّ الجهة التنظيمية، وسجّل رقم الترخيص والأذونات وأي سجلّ تأديبي.

**(ب)** ابنِ جدول مقارنة التكلفة الإجمالية لثلاثة وسطاء منظَّمين، مستخدمًا حجمك المقصود
الحقيقي ومدة احتفاظك. أيّهم أرخص لنمطك؟ وهل هو صاحب أضيق فارق سعري معلَن؟

**(ج)** لكلٍّ من ثلاثة وسطاء، سجّل الحدّ الأدنى لحجم الصفقة على أداتك. واحسب أدنى مخاطرة
يستلزمها كلٌّ منها بمسافة وقفك المعتادة، على حجم حسابك المقصود. أيّها قابل للاستخدام؟

**(د)** ابحث عن النسبة المنشورة لحسابات الأفراد الخاسرة لدى كل وسيط. وسجّلها. ولاحظ مدى
بروز عرض كلٍّ منها.

**(هـ)** اقرأ سياسة تنفيذ الأوامر لدى وسيط واحد كاملةً. ولخّصها في خمس نقاط: نموذج التنفيذ،
ومعالجة الانزلاق، والمسافات الدنيا، وشروط الإغلاق فقط، وكيف تُشتقّ الأسعار.
