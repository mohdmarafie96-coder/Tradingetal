# Module 08 — Building a Trading Plan

**Time:** ~5 hours · **Prerequisites:** Modules 05–07

A trading plan is a written document that specifies, in advance, every decision you will
make. Its purpose is not to guarantee profit. It is to ensure that your decisions are
made when you are calm rather than when you are in a position.

Without a written plan you are not trading a strategy. You are making a series of
unconnected decisions and calling the result a strategy afterwards.

## Lessons

1. [What an edge is](01-edge.md) — and how to tell whether you have one
2. [Writing the plan](02-writing-the-plan.md) — every component, with examples
3. [Journaling and metrics](03-journaling.md) — what to record and what to measure
4. [Testing](04-testing.md) — backtesting, forward testing, and how to fool yourself less

## Learning outcomes

By the end of this module you can:

- State what an edge is and name the realistic sources available to a retail trader
- Write a complete trading plan covering setup, entry, exit, sizing, risk limits and review
- Maintain a trade journal that supports genuine analysis rather than storytelling
- Calculate the metrics that matter: expectancy, profit factor, maximum drawdown, R-multiple
  distribution
- Design and run a backtest that avoids the main sources of self-deception
- Decide, on evidence, whether a strategy is ready for live capital

## Deliverable

By the end of this module you should have a **written trading plan** using the
[template](../../templates/trading-plan-template.md). It is the main input to the Module 11
capstone.
