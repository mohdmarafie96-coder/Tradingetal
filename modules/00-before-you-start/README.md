# Module 00 — Before You Start

**Time:** ~1 hour · **Prerequisites:** none

This module exists to make sure you begin with accurate expectations. It contains no
trading technique. Skipping it is the most expensive thing you can do in this course,
because everything that follows is only useful to someone who has correctly framed what
they are attempting.

## Lessons

1. [Is this for you?](01-is-this-for-you.md) — an honest expectations reset
2. [How this course works](02-how-this-course-works.md) — structure, pacing, study method
3. [Setting up a demo account](03-demo-account-setup.md) — your practice environment

## Learning outcomes

By the end of this module you can:

- State what proportion of retail CFD accounts lose money and why that figure is
  structural rather than incidental
- Describe the three costs that run against every position regardless of direction
- Explain why a demo account is a prerequisite and what it does and does not simulate
- Decide, with reasons, whether to continue
